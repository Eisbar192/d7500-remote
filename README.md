# D7500 Remote – iPhone-App

Eigener SnapBridge-Ersatz für die Nikon D7500.

- Fotos per WLAN von der Kamera direkt in die Fotos-App (RAW + JPG als ein Bild)
- Neue Fotos automatisch laden
- Fernsteuerung: Einstellungen, Scharfstellen, Auslösen, Live-Bild
- GPS wie bei SnapBridge: Route aufzeichnen, Fotos bekommen ihren Ort; Export als GPX

GitHub baut die App bei jedem Push automatisch (`.github/workflows/ios.yml`).
Die fertige Datei liegt unter **Releases → neueste → D7500Remote.ipa** und wird mit SideStore/AltStore installiert.
